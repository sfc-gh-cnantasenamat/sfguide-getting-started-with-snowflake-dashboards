# Getting Started with Snowflake Dashboards

Part 1 of the Snowflake Dashboards developer guides, by Chanin Nantasenamat. Run one SQL file, open one dashboard file, and explore a working revenue dashboard in about a minute. All data is synthetic.

- Guide: [`quickstart/getting-started-with-snowflake-dashboards/getting-started-with-snowflake-dashboards.md`](quickstart/getting-started-with-snowflake-dashboards/getting-started-with-snowflake-dashboards.md)
- Companion files (shared with Part 2): [getting-started-with-snowflake-dashboards](https://github.com/sfc-gh-cnantasenamat/getting-started-with-snowflake-dashboards). Part 1 uses the [`getting-started/`](https://github.com/sfc-gh-cnantasenamat/getting-started-with-snowflake-dashboards/tree/main/getting-started) folder: `setup.sql`, `revenue_pulse.dash`, and `cleanup.sql`.

Part 2, where you build this dashboard from scratch with Cortex Code, is [Build Snowflake Dashboards with CoCo](https://github.com/sfc-gh-cnantasenamat/sfguide-build-snowflake-dashboards-with-coco).

Clean up by running `cleanup.sql` with the role that ran `setup.sql`.
