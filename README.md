# Getting Started with Snowflake Dashboards

A Snowflake developer guide by Chanin Nantasenamat. Run one SQL file, open one dashboard file, and explore a working revenue dashboard in a few minutes. All data is synthetic.

- Guide: [`quickstart/getting-started-with-snowflake-dashboards/getting-started-with-snowflake-dashboards.md`](quickstart/getting-started-with-snowflake-dashboards/getting-started-with-snowflake-dashboards.md)
- Companion files: the [`getting-started/`](https://github.com/sfc-gh-cnantasenamat/getting-started-with-snowflake-dashboards/tree/main/getting-started) folder of [getting-started-with-snowflake-dashboards](https://github.com/sfc-gh-cnantasenamat/getting-started-with-snowflake-dashboards): `setup.sql`, `revenue_pulse.dash`, and `cleanup.sql`.

Clean up by running `cleanup.sql` with the role that ran `setup.sql`.
