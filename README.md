# Getting Started with Snowflake Dashboards

Part 1 of the Snowflake Dashboards developer guides, by Chanin Nantasenamat. Run one SQL file, open one dashboard file, and explore a working revenue dashboard in about a minute. All data is synthetic.

- Guide: [`quickstart/first-dashboard-with-snowflake-dashboards-2-0/first-dashboard-with-snowflake-dashboards-2-0.md`](quickstart/first-dashboard-with-snowflake-dashboards-2-0/first-dashboard-with-snowflake-dashboards-2-0.md)
- Companion files (shared with Part 2): [getting-started-with-snowflake-dashboards-2-0](https://github.com/sfc-gh-cnantasenamat/getting-started-with-snowflake-dashboards-2-0). Part 1 uses [`sql/quick_setup.sql`](https://github.com/sfc-gh-cnantasenamat/getting-started-with-snowflake-dashboards-2-0/blob/main/sql/quick_setup.sql) and [`dashboards/revenue_pulse.dash`](https://github.com/sfc-gh-cnantasenamat/getting-started-with-snowflake-dashboards-2-0/blob/main/dashboards/revenue_pulse.dash).

Part 2, where you build this dashboard from scratch with Cortex Code, is [Build Snowflake Dashboards with CoCo](https://github.com/sfc-gh-cnantasenamat/sfguide-getting-started-with-snowflake-dashboards-2-0).

Clean up with `DROP DATABASE IF EXISTS REVENUE_PULSE_DB;`.
